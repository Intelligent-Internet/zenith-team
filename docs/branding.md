# Zenith Team branding

Zenith is the shared brand prefix. This product is **Zenith Team**; other
products can use names such as Zenith Agent and Zenith Studio. Use the full
name “Zenith Team” in navigation, page titles, onboarding, product copy,
desktop menus, notifications, and release names. Keep the existing symbol.
The public website is https://app.example.com; canonical links, social metadata,
sitemaps, and frontend links to the public legal pages use this origin.

The September 11, 2026 update changes the display name. The September 15,
2026 CLI revision renames the command-line tool: the binary and every
command family are `zen` (`zen auth login`, `zen daemon start`,
`zen task get`); the old `boardly` command is gone. Other technical
identities remain stable: API origins, the `boardly-mcp` binary and the
`boardly` MCP server name, `BOARDLY_*` environment variables, the
`~/.boardly` state directory, desktop bundle IDs, deep-link protocols,
cookie and storage keys, and application data folders. This preserves
installed applications, authenticated sessions, and updates. New installer
downloads use the `Zenith-Team-` filename prefix.

Public legal copy uses the new product name with unchanged substantive terms.

External branding, including OAuth consent screens, hosted email templates,
and deployment domains, is managed in the corresponding provider configuration.
Repository changes do not publish those external settings.
