# Whiteboard export font

`NotoSans-Regular.ttf` is embedded in the Go server for deterministic PNG and
PDF rendering, including Vietnamese text. The server never fetches fonts or
executes a browser during an export. `OFL.txt` is the original SIL Open Font
License distributed with Noto.

Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
