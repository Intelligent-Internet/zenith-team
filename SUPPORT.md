# Getting help

| You need… | Go to |
| --- | --- |
| Help with setup or usage, or to share an idea | [GitHub Discussions](https://github.com/Intelligent-Internet/zenith-team/discussions) |
| To report a bug | [Open a bug report](https://github.com/Intelligent-Internet/zenith-team/issues/new/choose) |
| To request a feature | [Open a feature request](https://github.com/Intelligent-Internet/zenith-team/issues/new/choose) |
| To report a security problem | [SECURITY.md](SECURITY.md). Never a public issue. |
| To fix a common problem | [Troubleshooting](docs/content/docs/troubleshooting.mdx) |
| To read the docs | [The docs index](docs/README.md) |

## Before you ask

- Search [existing issues](https://github.com/Intelligent-Internet/zenith-team/issues)
  and [discussions](https://github.com/Intelligent-Internet/zenith-team/discussions).
- Say how you run Zenith Team: self-hosted, desktop app or from source.
- Include the version or commit, your OS, and your agent CLI and its version
  (`codex --version` or `claude --version`).
- For daemon or CLI problems, include the output of `zen doctor` and
  `zen daemon logs`.
- Remove tokens, passwords, API keys and other secrets before you paste
  anything.

## Response times

Maintainers and the community answer when they can. There is no guaranteed
response time for questions.

Our [Code of Conduct](CODE_OF_CONDUCT.md) applies in issues, discussions and
pull requests.
