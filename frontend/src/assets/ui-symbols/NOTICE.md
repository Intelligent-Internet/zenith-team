# UI symbols

## Highlighter

`highlighter.svg` is an original Zenith Team chisel-tip marker for Whiteboard
highlighting. The official Outline catalog was inspected for `highlighter` and
`marker` on 2026-10-10; the available results did not provide a verified suitable
Free marker glyph. This symbol uses the shared 24 × 24 grid, 1.5 px rounded
outline and `currentColor`. It is not Goodnotes artwork or an official Iconsax icon.

These small symbols are authored for Zenith Team, not official Iconsax artwork.
The bundled Iconsax Free catalog has no matching pushpin, @, or puzzle-piece glyph.
Use these symbols for Pin, Unpin, Mention, and Plugins so the controls retain their
familiar meaning.
They match the Iconsax 24 × 24 grid, 1.5 px line weight, rounded ends, and
`currentColor` behavior. The shared icon adapter identifies them with
`data-ui-symbol`, separately from `data-iconsax`.

Use Iconsax for other UI icons; do not substitute an unrelated Free glyph for an
established action symbol.

The owner confirmed on 2026-09-15 that these symbols may be reused in new UI.
Additional authored symbols are allowed when the Iconsax catalog lacks a
suitable glyph. Match the same grid, line weight, rounded ends/joins,
`currentColor` and visual weight. Add the SVG here, register it in the shared
adapter's `uiSymbols`, and record its purpose in this notice. Do not copy
artwork from another icon library or label authored symbols as official Iconsax.

## GitHub outline

`github-outline.svg` is an original Zenith Team outline symbol identifying the
GitHub skill source. The official Iconsax Outline catalog was searched on
2026-10-06; the GitHub results are Pro assets, outside this repository's Free
asset license. This symbol preserves the recognizable cat ears, body and tail
with the shared 24 × 24 grid, 1.5 px rounded strokes and `currentColor`.
It is not official GitHub logo artwork or an official Iconsax icon. The unchanged
official GitHub brand mark remains in `assets/brands/github.svg`.

## Mouse pointer

`mouse-pointer.svg` is an original Zenith Team mouse-arrow silhouette for
collaborator presence. The official Outline catalog could not be accessed on
2026-10-04; the bundled Mouse Square glyph does not communicate a conventional
pointer. This symbol uses the shared 24 × 24 grid and 1.5 px rounded outline.
Its fill follows `currentColor`; `--mouse-pointer-outline` allows a contrasting
outline for presence overlays and defaults to `currentColor`. It is not copied
from another icon library or labelled as official Iconsax artwork.

## Software diagram shapes

`shape-rounded.svg`, `shape-terminal.svg`, `shape-actor.svg`,
`shape-database.svg`, `shape-queue.svg`, `shape-cloud.svg`,
`shape-component.svg`, `shape-document.svg`, `shape-note.svg`,
`shape-lifeline.svg`, `shape-class.svg`, `shape-entity.svg` and
`shape-fragment.svg` are original Zenith Team geometric symbols for the
Whiteboard shape picker, added on 2026-10-11. Each previews the outline the
Board draws for that kind (see `board-shape.tsx`): a rounded box, a pill, a
stick figure, an upright and a lying cylinder, a cloud, a box with two tabs, a
box with a wavy bottom, a box with a folded corner, a lifeline's header and
dashed axis, a class box with two compartments, an entity with its columns and
a combined fragment with its operator tag and dashed divider. A picker button
must show the contour placed on the canvas, which the catalog's object icons do
not. The symbols use the shared 24 × 24 grid, 1.5 px rounded strokes and
`currentColor`. They are not copied from another library or labelled as
official Iconsax artwork.
